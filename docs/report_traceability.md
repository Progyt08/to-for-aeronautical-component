## Names cited in the thesis

The notebooks `Final.ipynb` and `experimental_compression.ipynb` and the file `Solido_half.stl` keep the names cited in the thesis, as do the figures F01, F02, F10_xx and the tables T01 to T09 and T10_xx.

The consolidation renamed some internal items:

| Earlier name | Name in this repository |
|---|---|
| `caracterizacion.ipynb` | `material_characterization.ipynb` |
| Spanish variable names (`elegidos`, `nodos_verde`, `masa`, ...) | English names (`selected`, `nodes_crit`, `mass`, ...) |
| `PA6_Multicarga_vf638_sec7.stl` | `PA6_Multiload_vf638_sec7p5.stl` |
| `block9_results/run_*/`, `thesis_figures/run_*/` | `results/verification/`, `results/thesis_figures/` |
